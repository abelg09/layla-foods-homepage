# Layla Homepage

Static prototype homepage for Layla, a consumer food brand from Pavilion Foods.

## Hosting

This site is ready for GitHub Pages. Push this folder to a GitHub repository, then enable Pages from the repository settings using the `main` branch and root folder.

## Local Preview

Run:

```sh
python3 -m http.server 5174
```

Then open `http://127.0.0.1:5174/`.
