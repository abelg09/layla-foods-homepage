# Layla Shopify Prototype

Static Shopify-ready prototype for Layla, including the homepage, collection page, product detail page, recipes, Layla+, B2B, account, cart, checkout and contact pages.

## Hosting

This site is ready for GitHub Pages. Push this folder to a GitHub repository, then enable Pages from the repository settings using the `main` branch and root folder.

## Local Preview

Run:

```sh
python3 -m http.server 5174
```

Then open `http://127.0.0.1:5174/`.

Key routes:

- `/shop.html`
- `/product.html?sku=47`
- `/recipes.html`
- `/recipe.html?recipe=butter-chicken-feast`
- `/layla-plus.html`
- `/about.html`
- `/b2b.html`
- `/cart.html`
- `/checkout.html`
